# Session Logs

Create one short Markdown file for each meaningful practice session using `YYYY-MM-DD.md`.

Suggested format:

## Practiced
- Vocabulary, grammar, listening, reading, or conversation areas.

## Strong
- Items demonstrated reliably, especially in production.

## Shaky
- Errors, hesitation, or structures that needed prompting.

## New
- Newly introduced vocabulary or grammar.

## Observations
- Brief patterns worth carrying into future lesson planning.

## Next session
- A few concrete priorities, not a fixed script.

Session logs should summarize evidence rather than reproduce the whole chat.
